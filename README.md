# dSPACE Agentic Hub

**The Open Hub for Agentic, Specification-Driven Engineering Workflows**

The **dSPACE Agentic Hub** provides a unified collection of MCP servers, skills, and AI-powered workflows that connect AI assistants directly to the dSPACE toolchain.

Built on the **Model Context Protocol (MCP)**, the Agentic Hub enables AI assistants to participate in specification-driven engineering workflows across the entire V-cycle—from requirements and system design to implementation, validation, calibration, and testing.

---

## Why Agentic Hub?

Modern engineering workflows span multiple tools and engineering artifacts:

- Requirements and work items
- System architectures and specifications
- Software and model development
- Simulation and virtual validation
- Hardware integration
- Calibration and measurement
- Automated testing and validation

Although these activities are connected logically, they are often disconnected operationally, requiring engineers to manually switch between tools, transfer context, and coordinate engineering artifacts.

The dSPACE Agentic Hub enables AI agents to interact directly with engineering tools and artifacts through MCP servers, SKILLS and Playguides, reducing friction across development workflows while keeping engineers firmly in control.

## MCP Servers

The Agentic Hub includes MCP servers for core dSPACE products. 

| MCP Server | Description |
|------------|-------------|
| **ControlDesk MCP** | Experiment control, measurements, calibration, and automation |
| **VEOS MCP** | Virtual ECU validation, simulation execution, and orchestration |
| **ConfigurationDesk MCP** | Configuration management, I/O mapping, and project setup |
| **SystemDesk MCP** | System architecture, AUTOSAR workflows, and model access |
| **Bus Manager MCP** | Communication configuration and network management |
| **Test Automation SDK MCP** | Test execution and automated validation workflows |


## What Makes It Different?

### Specification & Intent Driven

Engineering artifacts remain the source of truth. AI agents work alongside engineers and operate within existing engineering processes.

### Open by Design

Built on the Model Context Protocol (MCP), enabling interoperability across tools, AI assistants, and workflows.

### Model Agnostic

Use your preferred AI assistant and LLM provider.

Supported examples include:

- GitHub Copilot
- ChatGPT
- Claude
- MCP-compatible AI hosts

### Human-in-the-Loop

AI agents propose actions.

Engineers review, modify, approve, and execute them. Nothing happens without engineering oversight.
